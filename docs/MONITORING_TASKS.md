# 报表监控与异常提醒

本轮把“目录最近有没有文件”补充为可配置的“指定报表是否按时交付”。

- 规则新增 `file_keyword`，按文件名包含关系精确筛选，空值保留“目录内任一报表”的原有用途。百分号和下划线不作为通配符。
- 每日规则新增 `deadline_time`（默认 18:00）。按北京时间的自然日计算本期截止时间：今天截止前，核对最近一个已到期的周期；截止后，核对今天的非空匹配报表。不再把“昨天深夜更新过”当作“今天已更新”。
- 周、月和自定义周期保留按周期天数的当前时效判断。未来修改时间的文件不会满足当前交付要求。
- 证据返回具体报表、应更新时刻、最新非空匹配文件及时间、超时量、检测时刻和异常原因。若本期只有零字节文件，会标为“报表已提交，但文件为空”，保留上一次非空文件作为最近有效更新。
- 任务详情 `GET /api/archive/tasks/{task_id}` 与列表使用同一权限过滤层，与当前列表页码无关；无权限时返回 404，不透露任务对象。
- 首页提醒与归档列表突出监控对象、异常原因、应更新和最近有效更新。默认聚焦待处理异常，历史任务仍可切换查看。点击直接打开该任务详情，可定位目录、提交凭证、审核或查看凭证；既有状态流转仍由服务端校验。

提醒只依据已同步文件的名称、修改时间和大小判断，不推断网络故障或上游系统故障，也不把非空文件等同于业务数值已核对。只存在空占位文件、没有任何非空历史证据的规则，继续保留为待核对规则，避免虚构逾期交付。

升级采用新增字段迁移，保留已有规则及历史任务。演示模式单独管理几个样例监控；不修改成员授权。任务详情与提交/审核接口继续使用原有访问与角色校验。

验证：72 项测试通过，新增覆盖每日截止边界、时区、跨天、无关文件不能误消警、空文件、未来时间、字段保存/预检一致性、详情分页独立性和越权访问，以及演示报表差异与异常场景。
