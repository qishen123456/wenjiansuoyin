# 扫描与服务端限行预览

扫描使用共享目录队列动态分配工作，默认按 CPU 数设置 2～8 个线程（配置文件建议先用 4 个）；`SCAN_WORKERS` 可覆盖，硬上限 16。单写库线程消费有界文件队列，预加载元数据进行内存比对，无变化文件不执行逐条 SELECT 或扫描标记 UPDATE。每 300 个处理结果或 1 秒提交一次。网络读取位于生产线程，不占用数据库事务等待网络；队列等待时也会按时间释放已打开的写事务。

所有目录任务由队列 unfinished-task 计数收敛，不以瞬时“队列空”判断结束。异常/拒绝访问/断线记为 partial，禁止删除疑似失效索引；完整扫描后才按本次未见的旧记录 ID 清理，保留文件 ID、FTS 与现有权限/审批关联。扫描仍是全目录元数据遍历、增量写入，不宣称已实现 NAS 事件通知或秒级增量。不读取原表内容、不修改源文件。

`GET /api/file/{id}/preview-data?sheet=销售&page=1&page_size=100` 返回 JSON 单页数据，每页最多 200 行。最多显示前 10,000 行、100 列、每格 2,000 字符，工作表最多 50 个。行列计数只描述预览范围，不冒充全量统计。CSV 按行读取；xlsx/xlsm 使用 openpyxl 只读模式，公式只显示已保存计算值，不执行公式。旧格式用现有 pandas 引擎读取，单文件限制更小。

源文件默认 32 MB 上限；xls/xlsb/ods 不超过 16 MB，压缩工作簿展开总量不超过 128 MB。单进程仅允许一个未缓存解析，忙时返回 429 和重试提示；缓存上限 32 页或 16 MB、有效 60 秒，按来源路径、数据库、根目录、纳秒 mtime、大小及分页参数隔离。每次缓存读取前重新验证账号和目录权限，并返回 Cache-Control:no-store。解析期间源文件变化返回 409。

预览页和搜索结果切片均改用分页数据，不获取原表字节。原 preview-source 接口对普通成员返回 403，旧预览密钥不能绕过；管理员原件访问走下载接口。完整原件下载仍使用原审批流程。已获目录权限的用户能够看到预览范围内的数据，分页并非字段脱敏或防截图方案。

预览以数据网格为主，不保留原 Excel 的复杂样式、合并单元格或图表。超限原件可按既有审批下载；没有自动关闭审批门槛。4 GB 云主机建议先保持单应用进程，配置 SCAN_WORKERS=4，再做实际云盘/NAS 与并发验收。
