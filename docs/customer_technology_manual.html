WHY FASTER

把慢 I/O 与写库解耦

目录生产线程负责网络元数据获取；单消费者批量维护本地索引，降低 SQL 往返和事务频率。

FAIL-SAFE

扫描不完整，也不会误删历史

遇到拒绝访问、目录错误或文件异常，结果标记为“部分完成”；仅完整遍历成功才清理确实消失的索引记录。

关键边界：这是“全目录元数据遍历 + 增量写库”，不是 NAS 事件监听，也不是只扫描有改动目录的秒级增量。

扫描过程仅读取文件元数据，不修改原始文档；更新过程保留异常保护机制。

企业文件资产中心 · 技术说明检索机制

真正快的原因：用户搜索不再重新扫描网盘

SQLite FTS5 先召回候选，再由本地规则排序，兼容中文、英文缩写与目录线索。

01 · 建索引而不是反复找文件

预先记录文件标识、名称、目录、格式、大小、修改时间等信息；普通搜索只读本地索引。

02 · 关键词与中文片段召回

中文字符片段 + FTS5，支持名称/路径命中、严格匹配无结果后的宽松降级。

03 · 业务相关度综合排序

文件名精确命中、短词/英文缩写、文件类型与目录命中分别评分；修改时间可单独排序。

服务端解析与资源封顶

xlsx/xlsm 使用 openpyxl 只读模式；CSV 按行读取；源文件通常限制 32 MB，部分旧格式 16 MB；解压总体积 128 MB。

一次仅解析一份，短缓存复用

未缓存解析任务按序执行；60 秒内缓存最多 32 页或 16 MB；原件变化后失效。

SECURITY GATE

授权校验 → 限行解析 → JSON 返回

每次先按账号定位授权文件；缓存命中仍重新做权限判断；避免浏览器持久缓存，原件字节不通过预览接口下发。

预览不提供原始工作簿下载入口，完整原件由独立审批流程控制。

预览只返回限定范围内的数据；完整工作簿需依照下载审批流程获取。

企业文件资产中心 · 技术说明权限模型

先确认谁能看见，再决定哪些文件参与搜索

应用层目录 ACL 不仅保护详情页，也在召回、统计和分页前过滤。

POLICY ENGINE

成员 / 部门 + 精确目录

超级管理员向已有成员或部门授权目录；允许规则对子目录生效，拒绝规则优先，默认未授权不展示。

授权“财务 / 利润”时，界面可显示通向该目录的祖先节点，但不会自动暴露兄弟目录的文件。

01 · 请求建立权限上下文

从登录会话加载用户和部门授权策略，包含当前根目录作用域。

02 · SQLite 可见视图过滤

数据库可见范围隔离，把目录授权前置到 SQL 召回、统计和分页。

03 · 每次请求重新校验

AI 候选、预览、下载等走同一可见范围；撤权后新请求按新授权重验，授权动作留审计。

已做的是应用目录权限；它不自动继承 NAS/SMB 文件系统 ACL。实际访问仍由服务账号的共享盘权限决定，正式推广前需做身份与原生 ACL 对接验收。

目录授权在检索、统计、预览与下载时统一生效，并保留授权操作记录。

TECHNICAL CONTROL

单独的原件出口

下载服务定位文件并再次核验访问权限；普通成员持审批后的有效票据才能下载，管理员遵循现有角色直下规则。

USER EXPERIENCE

不强制安装客户端

浏览器内可以预览数据；复制共享路径供已接入网盘的电脑使用。远程网页不能直接启动访问者本机的 Excel。

限行是降低原件直接暴露面，不是字段级脱敏、DRM、防截图或防复制。需要敏感字段脱敏时必须另行制定并实现策略。

预览与原件下载分离：已授权可查看限定内容，获取完整文件仍须遵循对应权限与审批规则。
