# 演示下载审批

仅 DEMO_MODE=true 时，每日按日期、文件根目录和版本标记生成 14 条申请。同日刷新不重复生成，不覆盖人工处理结果；次日补充当天案例，保留历史。示例覆盖待审核、审核中、通过待下载、已完成下载、已驳回和过期未下载，引用真实的已索引非空文件，包含申请用途、审核意见及流程时间线。

演示记录通过 demo_key 标记，不生成有效下载票据，不被真实授权复用，不写入真实产品遥测。实际下载仍受账号目录权限与审批控制。演示申请可处理状态，但不产生真实授权。

review_note / workflow_events 字段用于记录审批意见和流程；旧记录用已有创建、审核、下载时间构造详情。演示事件不代表真实人员曾执行这些操作。
