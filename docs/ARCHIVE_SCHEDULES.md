# 归档检测日程

新规则将统计周期与交付截止时间分开。`schedule.mode=calendar` 使用自然日、自然周（周一至周日）、自然月；旧规则默认 `rolling`，继续按原周期间隔运行。新建页面默认下周第二天 18:00、遇休息日顺延；编辑旧规则不会自动改变其含义。

配置示例：

- 日报次日 10:00：daily、next、due_day=1、deadline_time=10:00。
- 周报下周二 18:00：weekly、next、due_day=2、day_basis=calendar。
- 月报下月第六个工作日 12:00：monthly、next、due_day=6、day_basis=workday。
- 额外延后 2 天：grace_days=2，沿用 day_basis 的自然日 / 工作日计算方式。

工作日计数与“遇假顺延”不同：前者计算第 N 个工作日，后者只在最终截止日为休息日时调整到下一个工作日，保留时分。可选择照常检测、不顺延；或跳过落在休息日的该期节点。跳过策略下，休息日不新增检测异常，已有历史待办不删除。企业额外休息日 / 工作日优先于基础日历，日期不能冲突。

选择下一周期时，交付窗口从下一周期第一天零点开始；选择本周期时从本周期第一天零点开始。文件必须非空，且最后修改时间落在交付窗口内，才作为交付证据；迟交文件可自动消结待办。不读取报表内容证明统计期，因此同名报表的内容归属仍需业务审核。检测使用北京时间，每分钟调度一次，到点后首次扫描执行，非毫秒定时器。

自然月第 31 天在不足 31 天的月份取月末。宽限在休息日顺延前计算。以已到期的最近节点检测；未来节点在预览中展示。休息日节点被跳过时，预览保留“跳过该期”记录。

中国日历内置 2026 年法定节假日与调休工作日，来源：国务院办公厅国办发明电〔2025〕7号，https://www.beijing.gov.cn/cs/gncs/zcwj/202603/t20260327_4568275.html 。不能把周末一律视作休息日，例如 2026-10-10 为补班日。尚未维护的年份会在预览中提示；涉及该年法定日历的检测暂停，不默认假定为普通工作日。可明确选择双休日历并配置企业日期，或在日历模块更新年度安排。

POST /api/archive/rules/schedule-preview 只计算日程，不保存、不产生待办。新建、编辑、预检和后台扫描使用同一个计算器；修改和启用规则均验证配置。
