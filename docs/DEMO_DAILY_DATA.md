# 每日演示数据与组织目录

本机 Demo 使用 `/Users/ltq/Desktop/项目/文件检索平台/网盘模拟数据`，已在本机配置启用 `DEMO_MODE=true`。默认配置和生产编排保持关闭。

服务启动、每天首次 API 请求，以及跨天后重新激活页面时，会按本地日期刷新演示报表。示例在已分类业务域的「每日经营报表」下生成真实 CSV，保留最近 7 天；报表包含业务日期、渠道、销售额、订单数、成本和毛利，可以搜索、预览和分析。页面及文件内容均标明演示数据。每天保留部分非活跃部门和一个逾期场景，避免所有指标始终一样。

生成器通过索引数据库 `app_meta` 中按根目录隔离的清单识别自有文件。不会覆盖、接管或清理已有用户文件；不跟随链接；遵守敏感目录和扩展名配置。关闭演示模式只停止自动生成与更新；切换到真实环境时应同时切换真实数据根目录，不把该模拟目录当作正式业务源。

## 组织与长字段

组织树参考企微通讯录：统一行高、蓝色文件夹、整行蓝色选中态，默认只展开根节点，部门按编号排列。箭头控制展开，选中部门查看文件；方向键浏览层级，搜索保留祖先。超深目录可以在树内横向滚动，完整名称同步显示在详情区。

右侧文件名称与相对路径完整换行；完整磁盘路径可悬停查看或复制。日期和操作按钮自适应换行。子目录默认展示 4 个，点击可展开全部；窄屏改为文件卡片，避免整页横向溢出。
