# 文件中心升级与部署说明

本地验证日期为 2026-11-07。浏览器入口位于人员权限、目录浏览和索引与同步。

## 文件权限与写入

在人员权限页选择成员或部门、文件夹和操作，点击“检查变更”比较新旧配置，再应用。模板包括只读、阅读并申请下载、阅读并上传。一次可处理 500 组组合。空文件夹可输入完整路径。子目录继承，明确禁止优先，多个下载来源中需审批优先于直接下载。查看最终权限可以核对个人和部门来源。

旧目录授权保留原有阅读与下载审批行为。上传和更新需另行授予。下载、分析明细导出和限时票据都校验当前下载权限。更新文件会使此前有效的下载票据过期。

目录浏览支持上传新文件和替换已有文件。演示模式可写。其他环境需要 FILE_WRITES_ENABLED=true、服务账号的写权限以及可写的存储挂载。默认生产编排挂载为只读。上传大小默认上限 32 MB。新增文件使用文件系统硬链接独占发布，在真实 SMB 上需验证支持情况。更新要求原文件版本匹配，成功后同步索引。经其他软件直接编辑的文件仍需扫描。对外部写入的修改冲突检测以文件状态为依据，NAS 多客户端并发写入需在现场验证。

原件旧副本位于索引数据库同级的 file_versions 目录。更新和恢复前都留存副本，恢复时核对校验值。生产需为此目录配置足够空间与留存策略。

## 在线预览

扫描格式白名单可加入 .ppt、.pptx、.jpg、.jpeg、.png、.webp。已有显式配置的环境需要更新 ALLOWED_EXTENSIONS 后重新扫描。图片可缩放、旋转。演示文稿转换为静态分页图片，最多展示前 100 页，不播放动画或视频。支持文件大小上限 32 MB。表格继续使用原有分页预览。

PPT 转换需要 LibreOffice Impress 及合适的字体。镜像构建文件已加入转换组件和中文字体。本机用真实 PPT、PPTX 完成过转换，云服务器的字体、资源和转换速度仍需实际验证。转换产物位于数据库旁 media_previews，浏览器通过鉴权接口获取当前页预览图。

## 同步和重建

“同步本目录”只核对此目录及其子目录。“全量扫描”遍历当前根目录，仅写入变化记录。“重建索引”重新生成检索词并保留已存在文件的编号，使用单个事务，完整扫描成功后提交。扫描报错时不清理疑似缺失记录，重建报错则回滚。本批移除了服务器本机打开文件的入口。

## 备份及恢复

系统按 BACKUP_INTERVAL_HOURS 检查数据库备份周期，默认 24 小时，设为 0 可关闭定时备份。BACKUP_KEEP_COUNT 默认保留最近 7 份。管理员也可立即备份和验证恢复。验证在临时数据库内进行。

默认备份位置为索引库旁的 backups。可通过 BACKUP_DIRECTORY 设置其他目录，Docker 部署需将备份盘挂载进容器。备份覆盖 SQLite 内的索引、账号、权限、监控与审批。NAS 原件、归档凭证附件、file_versions 和环境配置需要独立备份。同机备份不能覆盖整机故障。

恢复演练可运行：

    python scripts/restore_system_backup.py /备份盘/备份文件.sqlite3 /恢复目录/recovered.db

目标必须是新文件。恢复脚本检查数据库完整性并清理旧会话。正式切换时先停止服务，保留原库及其附属文件，再配置 INDEX_DB_PATH 为恢复库路径并启动。原数据源路径应与备份时一致。

## 飞书企业应用

在服务环境注入 FEISHU_APP_ID、FEISHU_APP_SECRET、FEISHU_REDIRECT_URI。回调地址使用服务的 HTTPS 域名和 /integrations/feishu/callback 路径，并登记到企业自建应用。生产网关若要求共享令牌，需按现有部署方案向 API 请求提供令牌。

企业管理员需授权通讯录读取和应用可见范围。启用通知时还需机器人发消息权限。人员权限页同步部门与成员，并由超级管理员把飞书成员绑定到已有平台账号。同步中断保留上次完整结果。同步本身不授予目录权限。绑定成员可从登录页使用飞书登录，离职或超出同步范围的身份无法再次通过飞书登录。本地账号停用和目录授权由管理员管理。

FEISHU_NOTIFY_ENABLED=true 后，后台检测新下载申请、审批结果以及匹配已绑定姓名的逾期归档任务，按接收人权限投递通知。业务审批继续在文件资产中心处理。飞书链路已使用模拟响应测试，真实租户登录、通讯录可见范围及通知投递需使用企业应用联调。
