# 界面与使用体验检查（2026-11-04）

本轮按普通员工实际操作流程检查首页、目录、归档、下载审批、成员管理、弹窗、文件预览和使用指南。

| 发现 | 已完成的调整 |
| --- | --- |
| “使用指南”实际是服务器迁移和部署文档 | 重写为面向员工的帮助中心，按搜索、目录、预览、下载申请、归档任务、管理审核组织；提供搜索、任务入口、FAQ 和返回工作台链接 |
| 月度图没有可读取的数值；本月与完整月份直接相连 | 增加数量刻度、月份数值、鼠标与键盘交互；本月虚线并标明进行中；移动端提供月份选择器；图表两端留白避免数据点裁切 |
| 业务域卡片用部门名搜索文件标题，可能出现空结果 | 点击直接定位到该目录，有今日更新时选中今日文件过滤，继续沿用现有路径解析和权限校验 |
| “需要你处理”实际上是当前可见范围的归档任务 | 改为“归档待办”，并明确显示范围；空状态只描述当前可见范围 |
| 按钮、输入框、弹窗、表格的层级和交互不一致 | 新增 `static/ui.css` 统一组件样式、焦点、悬停、按下、禁用和阴影；覆盖两种既有弹窗结构；窄屏弹窗内容可滚动 |
| 授权目录下拉被长路径撑宽 | 设置下拉与网格单元最小宽度、窄屏纵向排列；成员表格局部滚动，防止整页溢出 |
| 成员管理文案偏技术实现 | 改为“成员与访问权限”“成员列表”等用户可理解的标题，移除默认密码提示 |
| 预览页工具栏与主界面不一致 | 统一返回按钮、工作表标签和分页样式；长文件名完整换行 |

指南不展示服务器路径、部署命令或开发参数。只介绍现有可用操作，不把演示数据描述为正式业务结果，也不承诺未实现的脱敏预览。

验证：64 项既有后端回归通过；页面脚本语法检查通过。浏览器验证指南搜索、无匹配结果恢复、FAQ、图表月份点击与方向键、移动端月份选择、业务域直达今日文件及主要页面布局。桌面和移动端均检查横向溢出。
