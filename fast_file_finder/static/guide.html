01

第一次使用，三步就够了

拿到账号后，先体验找文件和查看内容。

初次使用
1

登录你的账号

使用管理员提供的账号和密码登录。没有账号，或忘记密码，请联系管理员。

2

输入两个关键词

例如“渠道 销售”或“投放 ROI”。先缩小范围，再用文件类型或日期筛选。

3

预览，确认是它

点击结果查看文件信息，再打开预览。需要保存到本地时，点击下载。

你只会看到已授权的文件。 没有可见文件时，联系超级管理员分配目录权限；无需自己修改目录或文件名称。

02

记得一点线索，就能开始找

不用输入完整文件名，也不用记住它放在哪一层。

用关键词查找

  1. 在首页搜索框输入业务、报表名称或指标，例如 销售 月报。
  2. 结果太多时，在搜索框下方按文件格式、日期或匹配方式缩小范围。
  3. 在结果列表选择文件，查看名称、所属目录、更新时间和内容预览。
没有结果？先删去日期、店铺全称等条件，换成一两个更常用的词。
搜索这样写
知道报表类型渠道 销售
知道业务指标投放 ROI
只记得大概需求点击右下角机器人，直接描述
AI 小助手点击右下角机器人，或按 ⌘ / Ctrl + J。例如：“帮我找广告投放 ROI 报表”。推荐结果受你的文件访问权限限制，请核对文件内容。启用模型时，问题和相关检索线索会发送给配置的模型服务，具体范围请咨询管理员。
去搜索文件
03

知道是哪个部门，就从目录进入

适合按业务域浏览，或连续查看同一目录里的文件。

  1. 进入左侧 目录浏览，在组织树中选择部门。
  2. 点击部门左侧箭头，展开下级目录；点击目录名称，查看右侧文件。
  3. 目录较多时，在树顶部搜索部门或目录名。也可以打开 仅看今日有更新部门。
  4. 右侧文件可以按名称、大小或时间排序。点击顶部路径中的任意一级，可以返回上层。
只被授权某个深层目录时，你会看到通向它的上级路径；这不代表同级其他目录也可以访问。
打开目录浏览
04

先看内容，再决定怎么用

预览用于确认内容，复制路径用于回到公司网盘。

在线预览

确认文件和工作表

点击 预览 在新页面查看表格，切换工作表或翻页。看见的名称、日期和字段与你要找的一致，再继续下载。

空文件没有可展示内容；大文件加载可能需要更多时间。
复制路径

在熟悉的网盘里打开

点击 复制 获取共享路径，在能访问公司网盘的电脑上打开。长文件名和目录路径也能在详情区完整查看。

电脑还需要具备相应网盘权限；平台授权不会代替网盘账号权限。

在线预览每页显示 100 行，最多查看前 10,000 行、100 列；超出范围或需要原始样式时，请按下载审批流程获取原件。

05

需要保存到电脑？查看下载权限

下载权限分为禁止、需审批和直接下载；需审批时填写用途。

成员操作
  1. 找到文件，点击 下载。
  2. 填写具体业务用途，例如“用于本周渠道销售复盘”，然后提交。
  3. 打开左侧 下载审批，查看自己的申请进度。
  4. 审批通过后，在有效期内点击 立即下载。如果已过期，重新提交申请。
填写用途→待审批→通过后下载
下载是否需要审批由文件夹权限决定。禁止下载时不能提交申请；审批通过后仍以当前阅读、下载权限为准。

06

把归档待办，处理到完成

首页“监控提醒”会显示相关提醒，归档合规页可以查看完整进度。

归档责任人
  1. 进入 归档合规，打开待处理任务，确认目录、更新频率和责任要求。
  2. 将要归档的文件放到任务要求的公司网盘目录。提交凭证并不会代替上传文件。
  3. 点击 提交凭证，填写完成说明并附上截图，再提交审核。
  4. 任务变为待审核后，等待管理员处理。如果被驳回，按审核意见调整后重新提交。

同步检测发现目录已有符合更新要求的非空文件时，相关待办也可能被自动关闭。零字节占位文件不能作为交付证据。

查看归档待办
07

管理与审核

仅在你拥有相应管理权限时，需要了解这一部分。

管理员

分配目录权限

超级管理员进入“人员权限 → 文件操作权限”，选择成员或部门及目录。子目录继承授权，拒绝规则优先；其他账号不会自动获得全盘访问权。

处理审核申请

在“下载审批”处理下载用途申请，在“归档合规”审核待办凭证。部门管理员只管理自己获准访问的目录。

设置归档规则

选择目标目录，填写报表关键词、统计周期和责任人，再设置当天 / 次日、下周或下月第几天几点检测。可按自然日或工作日计数，选择遇假顺延、照常检测或跳过，并预览最近检测节点，最后预检保存。确认目录确有文件；只有空占位文件时不能据此判断交付已达标。

检查同步情况

超级管理员可以在“索引与同步”刷新索引，查看最近扫描结果。文件在相应扫描完成后进入检索范围。扫描计划可配置，耗时随目录规模、网络和负载变化，可从这里查看进度。

“当前规则达标率”描述的是规则当前是否满足更新要求，不是历史上每次都按时完成的比例。
08

系统背后是怎么跑的？

为业务方和技术验收人员说明扫描、检索、AI、预览与访问控制的真实处理流程。

技术原理

基本架构：共享盘原件 → 后台目录元数据扫描 → 本地 SQLite / FTS5 索引 → 按登录账号过滤目录权限 → 文件搜索、AI 找表或按需预览。普通搜索不会重新遍历 NAS，也不逐个打开 Excel。

01 / 扫描提速

动态多线程扫描，增量写入

目录任务通过共享队列动态分配给扫描线程，默认根据 CPU 使用 2–8 个线程，可配置且最大 16 个；文件元数据经有界队列交给单个写库消费者。已索引文件在内存中按路径、大小与时间比较，无变化的不重复更新；写库默认每 300 条或每 1 秒提交。

扫描遇到访问失败时标记为部分完成，避免错误删除尚未确认消失的文件记录。仍需遍历目录元数据，并非 NAS 实时事件通知。
02 / 索引检索

搜索读本地索引，不读全盘正文

系统为文件名、目录、大小、格式与修改时间等元数据建立 SQLite FTS5 索引。使用中文字符片段、业务关键词、缩写和相关度评分召回候选，再按更新时间等条件缩小结果。

当前并未建立 Excel 单元格正文的跨文件全文索引；表内数据只在打开授权文件后按需读取。
03 / AI 找表

授权范围内先检索，再模型辅助

用户用业务语言提问时，先抽取主题关键词并检索已授权文件。直接命中就返回真实文件与目录；不足时可调用配置的主模型/备用模型，利用有限的已授权目录元数据提出替代搜索词或可能位置。

模型生成的目录推测不代表文件一定存在。启用外部模型前需确认文件名、目录名等元数据能否发送给服务商。
04 / 限行预览

服务端解析有限数据，浏览器不取原件

在线预览默认每页 100 行，最多 200 行；最多展示前 10,000 行、100 列、50 个工作表，每格最多 2,000 字符。服务端有文件大小、并发和短时缓存上限，返回分页 JSON 而不是整份 Excel 字节。

这属于限量展示，并非字段脱敏或防截图。要下载完整原件仍需执行既有审批。
05 / 权限执行

权限在 SQL 查询之前生效

超级管理员可以对成员或精确部门配置目录允许/拒绝规则。子目录继承，拒绝优先；请求按当前登录身份加载目录策略，SQLite 连接局部视图在召回、统计及分页前过滤未授权文件。

默认无授权无文件；权限变更后新请求重新判断。应用目录 ACL 尚不能替代 NAS/SMB 原生权限与企业 SSO。
06 / 审批与原件

看内容与拿走原件分开控制

在线数据预览和完整文件下载分别通过不同接口。普通成员对已授权文件提交用途、等待管理员审核；通过后使用限时下载票据，再由后端验证访问范围并返回原始文件。

网页不能从远端直接启动访问者电脑上的 Excel；复制共享路径仍要求终端有网盘访问权。
性能证据：仓库 2026-11-05 的本地模拟目录单轮实验，119,668 文件的无变化扫描由 11.685 秒降至 6.239 秒（约减少 47%），但峰值内存上升。该结果仅说明本地条件下改造有效，不能作为客户 NAS 的速度承诺。
生产验收边界：正式推广前，应验证真实 NAS 扫描与检索 P95、用户与原生文件 ACL 的映射、HTTPS / SSO、密码哈希迁移、敏感字段策略、审计备份与越权测试。系统当前可做有边界的试点，不宣称这些事项已全部完成。

09

可能会遇到的问题

先做这几项检查，通常就能继续工作。

为什么搜索不到文件？

先减少关键词和筛选条件，或按部门进入目录查找。仍然找不到时，请管理员确认该文件已同步、格式受支持，并且你拥有访问权限。系统不会展示未授权文件的名称或数量。

登录后没有可见文件，怎么办？

请联系超级管理员，为你的账号或所属部门分配目录访问权。没有授权时，文件数量可能显示为 0；更换搜索词无法解决权限问题。

为什么有的文件不能预览？

先检查文件是否为空、原文件是否移动或超过预览大小上限。繁忙时可能提示稍后重试；文件正在更新时请刷新后重试。预览仍失败，可以提供文件名和页面提示给管理员。

部门有今日更新，为什么仍有未更新提醒？

监控任务检查的是名称匹配的指定报表。部门里其他文件的更新，或仅提交了空文件，都不代表这份监控报表已完成交付。打开任务详情，查看应更新时间、最近有效报表和异常原因。

“今日更新”就是今天新增的文件吗？

它按文件的最后修改日期统计，包含今天修改过的旧文件，并不等同于今天首次上传的数量。月度图也按最后修改日期归集，本月尚未结束时不宜直接与完整月份比较。

演示环境里的报表可以当成业务结论吗？

不能。演示报表只用于体验功能，会按日期更新。实际工作请以公司正式业务文件为准。

点击复制路径后，为什么还是打不开？

请确认当前电脑已连入能访问公司网盘的网络，并具有网盘账号权限。平台内可见不等于当前电脑已经连接共享盘。
